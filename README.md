# Toolshop Enterprise Automation Framework

An enterprise-level E-commerce test automation
framework developed using Python, Selenium WebDriver
and Pytest.

## Technology Stack

- Python
- Selenium WebDriver
- Pytest
- MariaDB
- REST API
- Allure
- Docker
- Selenium Grid
- GitHub Actions

## Application Under Test

https://practicesoftwaretesting.com/

## Project Objectives

- Build a scalable automation framework.
- Implement Page Object Model.
- Automate end-to-end E-commerce workflows.
- Integrate API and database testing.
- Implement parallel and cross-browser execution.
- Configure Docker and Selenium Grid.
- Implement CI/CD using GitHub Actions.
